# Тропа · Войти в ритм

Мобильный прототип домашних тренировок с гантелями, скамьёй и эллипсом. Занятия открывают костры на карте. По умолчанию в маршруте четыре тренировки, по две на каждую из двух недель. У каждого занятия есть короткая версия. История и последние веса сохраняются в браузере.

Экран «Настройки профиля» открывается с карты. Здесь можно выбрать уровень, задать от одного до семи занятий в неделю и от одной до четырёх недель в маршруте, а также отметить домашний инвентарь. Карта показывает все остановки и прокручивается вбок на длинных маршрутах. План и замены учитывают доступное оборудование. Для кардио без эллипса предусмотрена ходьба с тем же таймером. На карточке занятия можно выбрать 20, 40 или 60 минут и независимо включить разминку и заминку. Каждый из этих блоков занимает пять минут из общего бюджета. В силовой длительность служит ориентиром.

Порядок упражнений меняется перетаскиванием за ручку или с клавиатуры. Костры с историей открывают прошлые записи по этой остановке, включая подходы, повторы, вес и длительность новых занятий.

В настройках можно выбрать дни тренировок, включить звук окончания отдыха и скачать или восстановить резервную копию. Ближайшее занятие можно перенести с карты. В календаре отмечены запланированные и выполненные занятия. В прогрессе по упражнениям нажатие на дату раскрывает подходы за это занятие. Оценка нагрузки из итогов занятия видна рядом с прошлыми подходами.

## Локальный запуск

Запусти из корня проекта:

```sh
npm ci
npm run dev
```

Vite покажет адрес разработки. Для проверки офлайна запусти `npm run build` и `npm run preview`. Открой адрес предпросмотра онлайн, дождись надписи «Маршрут доступен без сети», отключи сеть и перезагрузи страницу.

## Тесты и Storybook

- `npm test` запускает тесты Vitest. Они проверяют переход между остановками, запись подходов, таймеры, восстановление истории и подбор упражнений из Kinetic.
- `npm run storybook` открывает карту, тренировку и историю в разных состояниях. Интерактивные примеры тренировок используют отдельный прогресс.
- `npm run build-storybook` собирает каталог компонентов в `storybook-static/`.

## Архитектура

React, TypeScript и Vite. В FSD-слоях `app` собирает приложение, `pages` содержит экраны, `features/workout` отвечает за занятие и таймеры, `entities` содержит программу, каталог и прогресс, а `shared` — общие компоненты.

На карточке силового занятия можно выбрать одну или несколько групп мышц. План подбирает упражнения из Kinetic с учётом доступного инвентаря. Названия, инвентарь и инструкции доступны на русском. Сервис-воркер сохраняет каталог, поиск, планы и текстовые подсказки для офлайн-работы после первого открытия по HTTPS или через localhost. Для просмотра видео техники на YouTube нужен интернет. [Каталог Kinetic](https://github.com/kinetic-place/exercises-json) · [Лицензия MIT](public/kinetic-license.txt)

При обновлении Kinetic добавьте названия в `src/entities/program/kinetic.ru.json` и инструкции в `src/entities/program/kinetic.cues.ru.json` по исходным ID, затем запустите `node scripts/prepare-kinetic.mjs`. Скрипт проверит наличие переводов и обновит поля каталога. Приложение читает инструкции при открытии техники, а сервис-воркер заранее сохраняет их для офлайн-работы.

## GitHub Pages

1. В настройках репозитория открой **Settings → Pages** и выбери **GitHub Actions** в поле **Source**.
2. Отправь изменения в ветку `main`. GitHub Actions запустит `npm run build` и опубликует содержимое `dist/`.
3. Открой адрес из настроек Pages после завершения публикации.

На GitHub Free для такого размещения подходит публичный репозиторий. Прогресс с локального адреса и с GitHub Pages хранится отдельно. [Настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Форматирование и линтеры

- `npm run format` применяет Prettier к исходникам, стилям и конфигам.
- `npm run lint` запускает ESLint для JavaScript, TypeScript и React Hooks, затем Stylelint для CSS.
- `npm run check` проверяет форматирование, линтеры, типы и тесты.
- Husky запускает `npm run check` и `npm run build:check` перед коммитом. Проверочная сборка попадает в `.build-check/`.

Добавляй инструменты командой `npm install -D <имя-пакета>`. npm запишет диапазон версий в `package.json` и точные версии в `package-lock.json`. Для воспроизводимой установки используй `npm ci`, для обновления в пределах диапазонов — `npm update`.
