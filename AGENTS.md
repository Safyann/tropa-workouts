# Работа по этапам

- После каждого завершённого этапа с изменениями проверь diff, запусти предусмотренные проектом проверки и создай отдельный коммит перед переходом к следующему этапу.
- Включай в коммит изменения этого этапа. Чужие и несвязанные изменения оставляй в рабочем дереве.
- Выполняй push по явному запросу.
