# Тропа · Войти в ритм

Мобильный прототип домашних тренировок с гантелями, скамьёй и эллипсом. Четыре занятия открывают костры на карте. У каждого занятия есть короткая версия. История и последние веса сохраняются в браузере.

## Локальный запуск

Запусти из корня проекта:

```sh
npm ci
npm run dev
```

Vite покажет адрес разработки. Для проверки офлайна запусти `npm run build` и `npm run preview`. Открой адрес предпросмотра онлайн, дождись надписи «Маршрут доступен без сети», отключи сеть и перезагрузи страницу.

## Тесты и Storybook

- `npm test` запускает тесты Vitest. Они проверяют переход между остановками, запись подходов, таймеры, восстановление истории и обработку ответов ExerciseDB.
- `npm run storybook` открывает карту, тренировку и историю в разных состояниях. Интерактивные примеры тренировок используют отдельный прогресс.
- `npm run build-storybook` собирает каталог компонентов в `storybook-static/`.

## Архитектура

React, TypeScript и Vite. В FSD-слоях `app` собирает приложение, `pages` содержит экраны, `features/workout` отвечает за занятие и таймеры, `entities` содержит программу и прогресс, а `shared` — общие компоненты и клиент ExerciseDB.

Сервис-воркер сохраняет оболочку, планы, текстовые подсказки и локальные схемы базовых движений после первого открытия по HTTPS или через localhost. Полный каталог, поиск и GIF в карточках обращаются к ExerciseDB и требуют интернета. Замены берутся из локальной подборки по той же группе мышц, а в историю попадают выполненные подходы с фактическим названием упражнения. Источник каталога и GIF — [ExerciseDB / AscendAPI](https://oss.exercisedb.dev/docs).

## GitHub Pages

1. Собери `npm run build` и отправь файлы проекта, включая сборку `docs/`, в репозиторий GitHub.
2. В настройках репозитория открой **Settings → Pages**.
3. Выбери **Deploy from a branch**, опубликованную ветку и каталог **/docs**. Нажми **Save**.
4. Открой адрес, который появится в настройках Pages.

На GitHub Free для такого размещения подходит публичный репозиторий. Прогресс с локального адреса и с GitHub Pages хранится отдельно. [Настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Следующие этапы

- **Этап 2.** Добавить режим «Зал» как отдельную программу с тренажёрами и свободными весами. Домашний и зальный маршруты получат отдельный прогресс.
- **Google Play.** Для Android проверить упаковку PWA как Trusted Web Activity, подписать сборку и связать её с постоянным HTTPS-доменом через Digital Asset Links. Обычная страница проекта на GitHub Pages лежит в подкаталоге. Для TWA понадобится возможность разместить `/.well-known/assetlinks.json` в корне используемого домена. [Trusted Web Activity](https://developer.chrome.com/docs/android/trusted-web-activity)
